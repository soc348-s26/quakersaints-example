# quakersaints analyss: An example

This will provide a step by step example of analysis of a single book _Quaker Saints_.

You can use this as a kind of model for your own work.  I have included a lot of commentary about my thinking 
process.

You should know that the analysis took a lot of time to develop; I've been through each step multiple times. 
It is specific to this book. But also 
you should be able to follow a similar process for your book.  However, each book has its own special
issues that need to be taken into account.
